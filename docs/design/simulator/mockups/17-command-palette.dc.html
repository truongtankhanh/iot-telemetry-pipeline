Behaviour

⌘ Kopens it from anywhere; / too, outside a field
↑↓move; ↵ opens; ⌘ ↵ opens in the background
Esccloses it and returns focus to where it was

Type a prefix to narrow the group: d: devices, a: alerts, s: scenarios, > actions. Results are ranked by match quality, then by severity, so an open alert comes before a cleared one. Only the first 5 of each group show; the rest sit behind Show all.

At scale

With the command center's catalogue (31 assets) or more, search is how a device is reached: every list, graph and the twin accept a result by id.

Matching runs in the browser on the lists Studio already holds, so it costs no request; the event log is searched only inside the selected range.

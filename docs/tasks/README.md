# Tasks

Known risks, open decisions and follow-up work found while documenting and reviewing the repository,
grouped by the release they were raised against. A task stays in its version's folder when it is
done; its `Status` changes instead.

| Version | Scope                                                                | Index                        |
| ------- | -------------------------------------------------------------------- | ---------------------------- |
| V1      | Demonstration system, not intended for production use                | [v1/README.md](v1/README.md) |
| V2      | The pipeline becomes the single telemetry source (ADR-0007); on hold | [v2/README.md](v2/README.md) |

Tasks are separate from the [roadmap](../roadmap.md), which holds the numbered `ITP-*` tickets. A task can
be promoted to a roadmap ticket when someone commits to doing it. When a new version starts, add a
folder (`v2/`), an index in it, and a row above; task ids carry the version (`V2-T01`).
